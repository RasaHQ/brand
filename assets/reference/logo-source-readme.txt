RASA LOGOS — DIGITAL AND PRINT

Horizontal and square logo artwork, preserving the logo paths and original canvas proportions; trademark symbols removed at Karl’s request. Source files remain unchanged.

DIGITAL — RGB
SVG vector and transparent PNG (2400 px longest edge, embedded sRGB profile).
Ink: #181210 / RGB 24, 18, 16
Cream: #FAF6F0 / RGB 250, 246, 240
Pink: #E85A91 / RGB 232, 90, 145

PRINT — CMYK
Vector PDF and EPS, using the supplied process-colour recipes:
Ink: C71 M68 Y67 K84
Cream: C0 M2 Y4 K2
Pink: C0 M78 Y13 K0
No background panel is included. Cream artwork is intended for a contrasting background.
No printer-specific ICC profile or PDF/X certification is applied; agree the output profile with your printer. These are process CMYK files, not spot-colour separations.

Colour sources: Rasa-Colour-Primitives-Primary-Ramps-Website.pdf and RASA PRINT COLOURS.ai from the supplied Colours folder.
